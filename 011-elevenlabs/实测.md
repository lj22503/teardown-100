> 写完跟我说一句「ElevenLabs 实测好了」。

它是以家生成式语音公司，主打声音模型，然后提供了丰富的场景，如游戏，对话，旁边，角色，教育等等。
提供api和agent2个服务模式。

能够监控语音是否是合成的，这点挺好。
[ElevenLabs 定价｜黑色星期五特惠：最高省 55%](https://elevenlabs.io/zh/pricing)，它的定价也很有意思，
##### 让我们量身定制体验。你想用 ElevenLabs 做什么？

创作者内容播客与有声书营销与广告电影与电视音乐与音效设计游戏教育、培训与可及性配音个人使用 / 探索

提供的场景很多，但老是触发收费。然后我觉得它老是在流程里面报错。
它的定位更多的是面向创作者的。

## 先做一件事（8 分钟）

**照做**：做一段你真要用的语音

做完停下来，下面六维都从这一次体验里取证据。

## ① 替掉哪一步

> 它接管的这步，原来是怎么做的。

| 记什么                    | 我填                                         |
| ---------------------- | ------------------------------------------ |
| 这件事原来谁做、怎么做            | 我录了一段自己的声音，这个事情原来是直接去讲话，现在可以把声音放出来。        |
| 原来要多久（分钟），现在要多久        | 已经又很多平台支持录音了，现在提取声音之后可以覆盖不同的场景。            |
| 原来花多少钱（人工/外包/工具），现在花多少 | 如果只是免费用，又1w的额度。现在最低套餐也要1美元。主推的是创作者模式，22美元。 |

## ② 脏活谁干（5 分钟）

> 数据、权限、格式的麻烦，它自己啃还是甩回给你。

| 记什么                            | 我填                 |
| ------------------------------ | ------------------ |
| 它要求我手动补了什么（导数据、改格式、给权限、写说明），几次 | 不用                 |
| 哪些是我本来就得做的，哪些是它没做好推给我的         | 如果录音本身得自己录制，选声音也是。 |
| **甩回来的那部分，是不是这个品类真正的门槛**       | 它有点像声音组件库。         |

## ③ 出来能不能用（3 分钟）

| 记什么                      | 我填                                          |
| ------------------------ | ------------------------------------------- |
| 直接用 / 改一两处 / 基本重做（选一个）   | 可以直接用，也提供了修改机会，但要收费。                        |
| 如果要改，改的是哪一类（事实、语气、结构、格式） | 要改的话，我觉得是性格这块很重要，我录了声音但听的时候发现不像我自己，主要在性格这块。 |
| 会不会有人拿它直接对外发             | 主要用来创作，比如有声书，视频，个人分身等，单独发没有意义。              |

## ④ 错了怎么兜（2 分钟）

> 故意让它错一次，看它后面有没有补救机制。

| 记什么                               | 我填                      |
| --------------------------------- | ----------------------- |
| 它有没有标来源 / 给置信度 / 提醒我核对            | 它又内置了安全提示，能够识别哪些声音是克隆的。 |
| 我故意给错前提，它顺着编，还是纠回来                | 声音需要收费，它提供了收费机制。        |
| 兜底靠什么：规则校验 / 人工复核 / 可核对来源 / 什么都不兜 | 没有兜底机制                  |

## ⑤ 错一次多贵（2 分钟）

| 记什么                 | 我填          |
| ------------------- | ----------- |
| 最坏情况：这一步错了，下游要跟着改多少 | 每一次都消耗对应的积分 |
| 能不能撤回 / 有没有历史记录     | 它支持实时声音转换。  |
| 结论：错得起 / 错不起（选一个）   | 错的起。        |

## ⑥ 不用它的替代（2 分钟）

| 记什么                   | 我填                          |
| --------------------- | --------------------------- |
| 明天它消失了，我用什么顶上         | 用其他声音模型顶上，比如中文声音用minimax    |
| 那个替代方案差在哪（贵、慢、要学、没人会） | 模型它最好。中文配音minimax更便宜和符合中文习惯 |
| 结论：换得掉 / 换不掉（选一个）     | 换的掉。                        |
