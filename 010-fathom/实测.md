# 010 · Fathom · 实测表（20 分钟）

> 产品页：https://www.producthunt.com/products/fathom
> 官方一句话：AI notetaking that is out of this world.
> 框架：[[04-概念-应用层六维]]（六条，每条都要一个具体证据）
> 写完跟我说一句「Fathom 实测好了」。


它 是一款桌面应用，但在landing page上就展示了关于它可以干什么的所有信息，我觉得我们的forge或者类似产品也都得考虑这个点。

一方面是它做的好的页面结构和框架，对于应用类的软件来说可以迁移。
另外它的引导，在用户还没下载之前引导注册的流程就让用户逐步授权了各种会议工作相关的邮箱或者会议软件。最后一步才是下载app。

fathom的安装是浏览器打开的方式，它支持浏览器插件等等。


https://www.producthunt.com/products/fathom，这是竞品和资源。

## 先做一件事（8 分钟）

**照做**：用一段真实录音（中英混杂、多人抢话）跑一遍

做完停下来，下面六维都从这一次体验里取证据。

## ① 替掉哪一步

> 它接管的这步，原来是怎么做的。

| 记什么                    | 我填                                    |
| ---------------------- | ------------------------------------- |
| 这件事原来谁做、怎么做            | 原来是人去做，会议没法直接转化位行动，要发邮件做备案。           |
| 原来要多久（分钟），现在要多久        | 以前要花至少半小时，现在会议中就能够记录反馈                |
| 原来花多少钱（人工/外包/工具），现在花多少 | 原来人工，现在工具免费就很强大了，而且她提供了吩咐的api和ai接入支持。 |

## ② 脏活谁干（5 分钟）

> 数据、权限、格式的麻烦，它自己啃还是甩回给你。

| 记什么                            | 我填                             |
| ------------------------------ | ------------------------------ |
| 它要求我手动补了什么（导数据、改格式、给权限、写说明），几次 | 她需要我补充接入我常用的会议工具               |
| 哪些是我本来就得做的，哪些是它没做好推给我的         | 原来得有人做会议纪要，会议的下一步行动她也会提炼然后让人确认 |
| **甩回来的那部分，是不是这个品类真正的门槛**       | 人可以专注在会议上。                     |

## ③ 出来能不能用（3 分钟）

| 记什么                      | 我填                |
| ------------------------ | ----------------- |
| 直接用 / 改一两处 / 基本重做（选一个）   | 能直接用              |
| 如果要改，改的是哪一类（事实、语气、结构、格式） | 如果要改改的是会议的共识和行动清单 |
| 会不会有人拿它直接对外发             | 有，她本身主推团队使用       |

## ④ 错了怎么兜（2 分钟）

> 故意让它错一次，看它后面有没有补救机制。

| 记什么                               | 我填               |
| --------------------------------- | ---------------- |
| 它有没有标来源 / 给置信度 / 提醒我核对            | 她只如实记录会议，根据会议给结果 |
| 我故意给错前提，它顺着编，还是纠回来                | 同上。              |
| 兜底靠什么：规则校验 / 人工复核 / 可核对来源 / 什么都不兜 | 人工确认             |

## ⑤ 错一次多贵（2 分钟）

| 记什么                 | 我填                             |
| ------------------- | ------------------------------ |
| 最坏情况：这一步错了，下游要跟着改多少 | 不能错。因为这个会议是结果导向的。              |
| 能不能撤回 / 有没有历史记录     | 能，有历史记录，但那种一边谈话一遍形成销售决策知道的错不起。 |
| 结论：错得起 / 错不起（选一个）   | 错不起                            |

## ⑥ 不用它的替代（2 分钟）

| 记什么                   | 我填                                                                                |
| --------------------- | --------------------------------------------------------------------------------- |
| 明天它消失了，我用什么顶上         | 用其他免费会议记录工具顶上                                                                     |
| 那个替代方案差在哪（贵、慢、要学、没人会） | 识别率的稳定性问题                                                                         |
| 结论：换得掉 / 换不掉（选一个）     | 换的掉 。但对于直接时效性要求和销售成交要求很高的团队，换不掉。因为有人说原本以为她的买免费版肯定会引导升级，但没想到免费版很强大，越用越好用，越用发现功能更多。 |
