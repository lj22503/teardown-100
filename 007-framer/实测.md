# 007 · Framer · 实测表（20 分钟）

> 产品页：https://www.producthunt.com/products/framer
> 官方一句话：The AI design agent for every step from idea to launch
> 框架：[[04-概念-应用层六维]]（六条，每条都要一个具体证据）
> 写完跟我说一句「framer 实测好了」。

## 先做一件事（8 分钟）

**照做**：用它把一张真实的设计稿或截图做成能上线的页面

做完停下来，下面六维都从这一次体验里取证据。

## ① 替掉哪一步

> 它接管的这步，原来是怎么做的。它替换的是好的设计实现这一步

| 记什么                    | 我填                                      |
| ---------------------- | --------------------------------------- |
| 这件事原来谁做、怎么做            | 这一步原来是设计师自己做，通过设计评估和人工设计                |
| 原来要多久（分钟），现在要多久        | 好几个月，现在通过截图好的设计成品，然后再上面让AI换部件，现在只需要几小时。 |
| 原来花多少钱（人工/外包/工具），现在花多少 | 原来需要设计师，现在只需要工具。                        |

## ② 脏活谁干（5 分钟）

> 数据、权限、格式的麻烦，它自己啃还是甩回给你。

| 记什么                            | 我填                                |
| ------------------------------ | --------------------------------- |
| 它要求我手动补了什么（导数据、改格式、给权限、写说明），几次 | 它要求我找示例。给需求。                      |
| 哪些是我本来就得做的，哪些是它没做好推给我的         | 设计想法是本来就需要我做的，它这部分不覆盖，但提供了很多案例模板。 |
| **甩回来的那部分，是不是这个品类真正的门槛**       | 是。关于审美的判断。                        |

## ③ 出来能不能用（3 分钟）

| 记什么                      | 我填                  |
| ------------------------ | ------------------- |
| 直接用 / 改一两处 / 基本重做（选一个）   | 能直接用                |
| 如果要改，改的是哪一类（事实、语气、结构、格式） | 改的是每个组件细节           |
| 会不会有人拿它直接对外发             | 直接支持外发，它是一站式网站生成工具。 |

## ④ 错了怎么兜（2 分钟）

> 故意让它错一次，看它后面有没有补救机制。

| 记什么                               | 我填               |
| --------------------------------- | ---------------- |
| 它有没有标来源 / 给置信度 / 提醒我核对            | 它会提前让我选择。        |
| 我故意给错前提，它顺着编，还是纠回来                | 它不处理这种事情，判断它不负责。 |
| 兜底靠什么：规则校验 / 人工复核 / 可核对来源 / 什么都不兜 | 人工兜底。            |

## ⑤ 错一次多贵（2 分钟）

| 记什么                 | 我填           |
| ------------------- | ------------ |
| 最坏情况：这一步错了，下游要跟着改多少 | 它的设计结构都是可拆解的 |
| 能不能撤回 / 有没有历史记录     | 它支持undo，有记录。 |
| 结论：错得起 / 错不起（选一个）   | 错的起。         |

## ⑥ 不用它的替代（2 分钟）

| 记什么                   | 我填                                                                                                                    |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 明天它消失了，我用什么顶上         | 它提供了很多竞品：[Framer vs Wix: Design Platform or Business Suite?](https://www.framer.com/compare/framer-vs-wix)，或者我也可以回归本身 |
| 那个替代方案差在哪（贵、慢、要学、没人会） | 要调研下。调研结果在：同目录下。Framer调研报告-插件资源与MCP接入指南，Framer资源体系总览与前端重构可行性评估                                                        |
| 结论：换得掉 / 换不掉（选一个）     | 换的掉。                                                                                                                  |

## AI 类型（只当备注，不参与判断）

> 拔电测试：拿走 AI 后，产品还剩什么。

- 备注：**嵌入**（工具型建站产品，AI 只做生成首屏与文案，不在主链路）
- 我的确认：嵌入（拔电后 Framer 仍是建站工具）

## 最后三问（一句话就够）

| 问题               | 我填                          |
| ---------------- | --------------------------- |
| 1. 它省的那一步，值不值这个价 | 省的是制作过程，值这个价。               |
| 2. 它的门槛在模型，还是在别处 | 门槛在产品本身的seo，以及设计用户的习惯，在软件。  |
| 3. 我会不会留下，为什么    | 我会留下，针对免费用户也有很好的价值，比如模板和社区。 |
|                  |                             |

---

**三条必须给结论**：① 值不值这个价；② 门槛在模型还是在别处；③ 会不会留下。

值。门槛在软件本身。会留下。
