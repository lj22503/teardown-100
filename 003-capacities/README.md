## 三、校正后的四栏

- **一句话定位**：它卖的不是 AI，是「你不用再花三个月把笔记系统搭出来」——把 PKM 圈最贵的隐性成本（配置与维护）直接抹掉。
- **核心优势（1 条）**：**放弃自由度换来的开箱结构**。不给你插件、不给你文件夹、不给你自定义脚本，只给你对象类型；代价是你的系统长什么样它说了算，收益是你第一天就能用。
- **最大短板（1 条）**：**移动端不是同一个产品**。桌面端被评 "lifechanging"，iOS 端被评 "barely functional"——不能建 object 类型、分享面板坏数月、同步要重启、iPad 分屏布局错乱。（评论证据见第四节，我的实测待补）
- **失效场景（用评论证据，不用推测）**：
  1. **靠手机 captured 的人**：Apple Notes 3 秒能记完，Capacities 要等它不卡——3★ 原话「我仍然用 Apple Notes 做随手记录，Capacities 只放项目笔记」
  2. **存量迁移者**：PH 3★ 原话「唯一阻止我每天用并付费的就是批量导入」——迁移成本直接卡住付费转化
  3. **团队 / 需要合规的人**：官方自己写在"不做"里（团队版、E2EE），不是暂时缺，是路线外

## 五、附录四段结论摘要

- **16 对标竞品地图**：官方 `/compare` 目录在，`/compare/{obsidian,evernote,tana,heptabase,anytype,notion}` 全部可访问；`/vs`、`/alternatives`、`/switch` 全部 404。**它把"打谁"写进了 URL 结构**：打的是"存量迁移者"（都从 Obsidian/Evernote/Notion/Tana/Anytype 搬过来），不打的是"团队协作"（官方路线外）。PH 的 Similar Products 又是另一套名单：Obsidian、Craft.do、Bear、Reflect、Tana——**用户视角的相似 ≠ 官方视角的对手**。
- **17 竞品技术底座**：Obsidian＝本地 Markdown 文件 + 插件（锁住"可迁移/可 agent 化"，锁死"开箱即用"）；Anytype＝本地优先 + P2P + E2E + 开源（锁住隐私，锁死同步稳定性）；Tana＝supertag 大纲 + 查询（锁住重流程用户，学习曲线最陡）；Heptabase＝白板为核心的卡片（锁住学习/研究场景）；Notion＝云端块 + 数据库（锁住团队与权限）。Capacities＝云端对象 + 内建功能 + 无插件，**用"不做"换来一致性与速度**，代价是隐私叙事与可扩展性永久缺位。
- **18 可迁移的机会（我的判断）**：① 一整套"官方对比页 + 官方不做什么页"是零成本的信任与 GEO 资产，任何 to-C 工具都能抄；② 它公开的短板是导入，做一次性迁移服务可以吃到它的高意愿用户；③ 移动端只做 capture 不做编辑，把"3 秒记下"做成硬指标，比追平桌面功能便宜得多。
- **19 流量与变现拆解**：钱从"买了 3 个笔记软件还没找到系统"的知识工作者兜里出；这钱还能拿多久取决于它能否在 AI 时代把"结构"卖成"判断力"；它凭什么拿到——对比页吃长尾搜索（"capacities vs obsidian"这类意图最靠近付费）＋ Reddit 原话做信任 + Believer 做社群。变现三层：Pro 订阅（$9.99-119/年）→ Believer（信仰层溢价）→ AI 加包/API。**最脆的一根梁是渠道价差与移动端体验**，因为那正好是差评的落点。

## 六、待验证（留给实测）
