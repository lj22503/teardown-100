## T1 主链路（10 分钟）— 验它的核心承诺

**材料**：拿你自己真实的一批东西，不要用它示例库。建议就用 `D:\ObsidianVault` 里同主题的 3-5 篇（比如某个项目 + 相关人物 + 一本书）。

1. 注册 → 建一个 space → 新建一个自定义 object 类型（比如"客户"或"课程"），加 2 个属性
2. 把 3 条真实素材各建成一个 object，属性填满
3. 在其中一篇里引用另两个 object，回头打开被引用那个看反向链接有没有自己长出来
4. 打开今天那篇 daily note，看它有没有把刚才的创建记成时间线

**要记的三件事**
- 从登录到第一个"像样"的 object 出现，几步 / 几分钟
- 哪一步停下来想了"下一步该干嘛"（具体是哪一步）
- 第一次做出来的东西，改了几次才觉得能用

他在注册环节就直接进行了怎么使用的引导。
他覆盖了很多公开的信息，用户输入书籍，比如《深度工作》，他自动生成了对应的结构化信息，不需要人去打。

他的对象很清晰：书，项目，人，每天笔记。灵感。
他在每一个内容里面植入了默认案例，用它自己的文档。让人一下子就知道是干嘛的。

我觉得它的这一套可让AI学习，简直做personal agent结构化处理的一个很好的样本。——最好AI可以对数据的字段进行合理有效定义。

## T3 钱（3 分钟）— 只用免费版，找墙

不付钱。走：建 object 类型 → 用查询 → 用 AI → 用日历/任务。

AI助手只在pro付费中提供。

Capacities 支持以下 AI 功能：

- **[AI聊天](https://docs.capacities.io/reference/ai-assistant#ai-chat)**：在左侧边栏的**探索**中，或使用键盘快捷键与AI聊天。你可以把块或笔记传递给你作为上下文。上下文是每条消息中选择的。AI会根据你的笔记回答，可以规划多步骤工作，并能提出创建和更新建议供你批准。聊天记录在第一条消息后被保存为对象。`@`
- **[AI面板](https://docs.capacities.io/reference/ai-assistant#ai-panel)**：在选择内容块后，您可以快速启动AI面板，执行翻译、重写或摘要等任务。
- **[AI自动标记](https://docs.capacities.io/reference/ai-assistant#ai-auto-tagging)**：AI从**你现有的标签**中识别相关标签，并将其分配给该对象。如果需要，之后可以编辑选择。
- **[AI收藏选择](https://docs.capacities.io/reference/ai-assistant#ai-collection-selection)**：AI会从**你现有的收藏**中识别相关集合，并将其分配给该对象。如果需要，之后可以编辑选择。
- **[AI属性自动填充](https://docs.capacities.io/reference/ai-assistant#ai-property-auto-fill)**：你无需手动填充自定义对象的属性，而是依靠AI模型的知识自动填充。
- **[AI图像分析](https://docs.capacities.io/reference/basic-types/images#ai-image-analysis)**：只需一键即可分析任何图像。AI会提取标题、描述、文本（OCR，包括手写文本）、色彩调色板和分类。所有结果都会自动写入图像属性。
- **[Ask AI 指令](https://docs.capacities.io/reference/ai-assistant#ask-ai-command)**：一种快速便捷的提问方式，无需启动 AI 聊天。只需在内容的新块内输入你的问题，然后输入“/Ask AI”，你就会在下面看到该问题的回答。
- **[AI查询生成](https://docs.capacities.io/reference/ai-assistant#ai-query-generation)**：创建或编辑查询时，描述你想要的列表并按下回车键。容量是基于这个描述构建查询。

**要记的三件事**
- 墙在第几步出现（基本上不会触发，除了任务和探索模块）
- 文案卖的是"额度"还是"能力"（AI拥有完美的上下文，前往激活并配置 AI 的容量。`Settings > AI Assistant`

如果你在Capacities中使用AI特征，部分数据将被共享给选定的模型提供者。**如果你不使用任何AI功能，数据不会被共享**.）
- 关掉升级提示后，免费功能还能不能正常用（能，它甚至进行了强隐私提示）

**特别留意**：免费版给了无限 object，等于把"整理"白送，把"调用/回顾"收钱——验证一下是不是真的这么切。
