## T1 主链路（10 分钟）— 验它的核心承诺

**材料**：拿你自己真实的一批东西，不要用它示例库。建议就用 `D:\ObsidianVault` 里同主题的 3-5 篇（比如某个项目 + 相关人物 + 一本书）。

1. 注册 → 建一个 space → 新建一个自定义 object 类型（比如"客户"或"课程"），加 2 个属性
2. 把 3 条真实素材各建成一个 object，属性填满
3. 在其中一篇里引用另两个 object，回头打开被引用那个看反向链接有没有自己长出来
4. 打开今天那篇 daily note，看它有没有把刚才的创建记成时间线

**要记的三件事**
- 从登录到第一个"像样"的 object 出现，几步 / 几分钟
- 哪一步停下来想了"下一步该干嘛"（具体是哪一步）
- 第一次做出来的东西，改了几次才觉得能用

## T2 边界（5 分钟）— 必须给结论

**喂脏输入**，选一个：
- A 贴一篇 8,000 字以上、术语密集的真实长文（比如一篇基金合同或研报），让它提炼成 object + 属性
- B 贴两份互相矛盾的材料（比如同一件事的两个版本记录），看它有没有指出矛盾

**要记的三件事**
- 它有没有主动指出矛盾 / 术语不确定
- 错的时候是"明显错"还是"通顺地错"（这一条最重要）
- 有没有提醒你核对来源

**必须回答**：我的判断「对象模型在脏材料上会失效，因为它要求你先决定'这是什么'」——**成立 / 不成立**，一句话理由。

## T3 钱（3 分钟）— 只用免费版，找墙

不付钱。走：建 object 类型 → 用查询 → 用 AI → 用日历/任务。

**要记的三件事**
- 墙在第几步出现（第几次操作）
- 文案卖的是"额度"还是"能力"（原话抄下来）
- 关掉升级提示后，免费功能还能不能正常用

**特别留意**：免费版给了无限 object，等于把"整理"白送，把"调用/回顾"收钱——验证一下是不是真的这么切。

## T4 时间（2 分钟）

掐表：从打开官网到"能写出第一篇能看的笔记"。

- 几分钟 / 要不要先看文档或视频 / 有没有假进度条

## T5 AI 是否必须（5 分钟）— 必须给结论

**同一任务做两遍**：把一篇真实长文整理成带属性的 object。

- 第一遍：**不开 AI**，纯手动建 object、填属性、挂链接，掐表
- 第二遍：**开 AI**（属性自动填充 / 让它读这篇并建议类型与属性），掐表

**要记的三件事**
- 手动几分钟，AI 几分钟，差多少
- 增量性质：是"做不了 → 做得了"，还是"慢 → 快"
- 模型再强一档，它是变强还是被吞（官方自己说 AI 要 "stay assistive"，验证这句话是真的克制还是没做完）

**必须回答**：AI 对 Capacities 是**核心**还是**加速器**，一句话理由。
