## 〇、AI 类型判定（先判，再写别的）

**结论：嵌入型（Embedded）。**

- **拔电测试**：拿掉 AI，Figma 仍是一个完整的设计协作工具——画布还在、图层树还在、组件与变体还在、Dev Mode 还在、评论与多人光标还在。不是"能看不能用"，是**照常干活，只是慢一点**。所以判为嵌入型，不是 AI 原生。
- 与 006 Claude 的区别在这里是决定性的：Claude 拿掉模型只剩一个空的输入框；Figma 拿掉模型剩下一整套生意（行业默认的文件格式、组件资产、协作网络、交付链路）。
- **类型决定死法**：嵌入型的风险不在"被上游吞"，在"**被 AI 生成类的侧翼绕开**"——当一句话生成可跑界面的工具补上"可编辑的画布 + 团队协作"，它剩下的差异只有组件体系与交付链路，而这两样恰恰靠时间堆。反过来说，它的 AI 最容易被追平，所以它把 AI 做成 credits 计量，而不是主卖点。这是清醒的。

## 三、校正后的四栏

- **一句话定位**：**它不是"AI 设计工具"，是"设计协作的默认工作台"**——AI 只是后来加上去的一层，主路径仍是文件与画布。
- **核心优势（3 条）**：
  1. **多人同文件不是功能，是产品前提**。光标、评论、分支、版本全在文件里，"对齐版本"这件事从流程里消失了。这是最难被替代的一条，因为它靠的是团队的网络，不是代码。
  2. **组件与变体让设计变成系统**。改一次处处生效，于是用得越久资产越厚、越走不动——这条优势的时间函数是递增的。
  3. **生成出来仍是可改图层**。实测（燃冰）最要紧的一句：出来的不是一张图，是能改的文件，连空仓状态、模拟数据声明、风险声明都还在。这在生成类工具里现在还稀缺。
- **最大短板（2 条）**：
  1. **账单不可见地长大**。席位按三类分价、共享即可产生计费、credits 再叠一层；负面反馈里有两条独立证据（升 full member 计费 14 个月、重复收费承认错误却不退）。用户不是不肯付，是**看不见数字怎么涨的**。
  2. **所有权与权限的洞**。文件归个人，团队管理员改不了；所有者一离职，文件成孤儿，极端情形是账号被关、三年稿子一起没了。对代理商与外包协作，这是成交门槛而不是体验瑕疵。
- **失效场景（实测 + 评论证据，4 条）**：
  1. **要代码主权与自部署的人**：去 Lovable / v0 / Claude Code（生成物天生是工程产物，源码可导出）。
  2. **预算或合规必须自托管的人**：去 Penpot（开源、可自建）。
  3. **只要设计稿直接上线的人**：去 Framer（画布即生产环境，不用导出）。
  4. **把设计资产当公司资产托付的代理商**：权限与所有权一旦出问题，丢的不只是一个文件，是三年交付物与推荐意愿。

## 五、评论证据

**Product Hunt**：元数据抓到（4.9 / 1,609 条 / 15K 关注 / 36 次 Launch），但评论正文本次抓取失败，返回 0 条，**因此本卡不引用任何 PH 原话**，也不拿它替代用户声音。

**G2（直接抓取）**：4.7 分 / 1,598 条；分布 5 星 82%、4 星 16%、3 星及以下 0%。抓到的 10 条负面原话来自「What do you dislike」字段（G2 这个字段连 4–5 星用户也会填，所以它代表"不满意的地方"，不等于低星评价）。归纳四类：

1. **席位与账单**：外部协作者被系统升成 full member，会计师 14 个月后才发现；同一文件用不同账号操作造成重复收费，被承认是他们的错误却不肯退。
2. **权限与所有权**：Team Administrator 改不了别人名下的文件权限，原话自嘲"我是团队管理员，难道联系我自己？"；所有者离开就基本等于失去整个文件；极端情形是账号被关、三年作品一起没。
3. **大文件性能**：组件库大、画板多、复杂协作时卡顿与内存压力明显，重度会话能把浏览器标签跑崩（原话称在高配机器上也会）。
4. **免费与观看侧体验**：免费档封掉 inspector（原话：现在改叫 dev node 了），老用户说"现在没法用了"；设计师分享链接给非设计者，对方看不懂怎么点，原话形容消费端体验很糟。

**读法**：G2 4.7 与一星抱怨并存，说明**产品满意 ≠ 商业满意**。夸的集中在协作与易上手，骂的集中在钱与权——这两类评价指向的是两个不同的系统，不是同一个产品的两面。

## 六、附录四段

1. **竞品地图**：Figma 在地图正中，四面是 Sketch（存量 Mac 设计）、Penpot（自主可控）、Framer（设计即上线）、Webflow（技术 SEO）、Lovable / v0 / Claude Code（代码起手）、Canva（非设计师）。没有一个对手同时具备「多人同文件 + 组件体系 + 交付链路」三件套；真正的危险不是被抢，是**增量团队从代码起手、压根不进设计工具**。
2. **竞品技术底座**：Figma 是自研浏览器渲染引擎 + 实时同步 + 云端文件 + 插件沙箱 + Dev Mode 代码映射 + MCP 服务；接缝在"导出之后"。Framer 把接缝抹平（画布即生产，也因此没有代码导出），Lovable/v0 让接缝就是代码。**真护城河不在模型层**，在同步内核、文件格式的行业默认地位与组件资产的耦合——三样都得靠时间。
3. **可迁移的机会（我的判断）**：①加入即计费做成事前提示（最轻，一个弹层）；②credits 做成可见预算条（实测第一次用完免费额度无预警）；③生成结果做成带 diff 的审阅（原话只说"能改图层"，没说改了什么）；④文件所有权与个人解耦（对代理商是成交门槛，最贵也最值）。
4. **流量与变现拆解**：钱从三方出——做设计的人（Full 席位）、只读代码的人（Dev）、只评论的人（Collab），再叠一层按量 credits。流量吃长尾（Community 公开文件与插件可搜索、作品集与设计教育持续供人、36 次 Launch 供波峰）。变现三段：**订阅（广度）→ 席位类型（厚度）→ credits 与加购（深度）**。最脆的梁是"分享免费 vs 协作可能计费"与"文件归个人所有"同时成立：前者让账单自己长出来，后者让资产归属说不清。
