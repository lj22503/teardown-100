# 009 · Figma · 实测表（20 分钟）

> 产品页：https://www.producthunt.com/products/figma
> 官方一句话：The collaborative interface design tool
> 框架：[[04-概念-应用层六维]]（六条，每条都要一个具体证据）
> 写完跟我说一句「Figma 实测好了」。

## 先做一件事（8 分钟）

**照做**：用它在真实项目里改一个界面或做一版设计稿

做完停下来，下面六维都从这一次体验里取证据。

## ① 替掉哪一步

> 它接管的这步，原来是怎么做的。

| 记什么                    | 我填             |
| ---------------------- | -------------- |
| 这件事原来谁做、怎么做            | 设计师做，现在也还是设计师做 |
| 原来要多久（分钟），现在要多久        | 只是现在更快         |
| 原来花多少钱（人工/外包/工具），现在花多少 | 现在花的是16美元的订阅费  |

## ② 脏活谁干（5 分钟）

> 数据、权限、格式的麻烦，它自己啃还是甩回给你。

| 记什么                            | 我填                                                                                                                                                                                                                                                                            |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 它要求我手动补了什么（导数据、改格式、给权限、写说明），几次 | 我是直接把我线上某个不合适的页面发给他让他按照我的想法改版。这个是一个桌面投资工作台，我觉得我现在设计的太丑了，可能不符合用户的使用习惯，我希望调整成左侧抽屉，然后展示要符合金融卡片的样式。帮我调整看看                                                                                                                                                                         |
| 哪些是我本来就得做的，哪些是它没做好推给我的         | 然后它做的结果是：我按你的原稿做了一版：<figma-node-link node-id="2:2">MangoForge · 桌面投资工作台</figma-node-link><br><br>- **左侧抽屉式导航**：按市场洞察、组合风控、学习复盘分组，替代移动端底部导航。<br>- **金融卡片布局**：突出行情数字、涨跌幅和资产指标，保留红涨绿跌，方便快速扫读。<br>- **清晰的信息层级**：先看大盘和资产，再进入投资流程、工具与学习内容。<br>- 保留奶油底色与芒果橙，同时保留未录入持仓状态、演示数据说明和免责声明。 |
| **甩回来的那部分，是不是这个品类真正的门槛**       | 甩回来的是设计师自己的判断。没用判断做不好指挥。                                                                                                                                                                                                                                                      |

## ③ 出来能不能用（3 分钟）

| 记什么                      | 我填              |
| ------------------------ | --------------- |
| 直接用 / 改一两处 / 基本重做（选一个）   | 能用。             |
| 如果要改，改的是哪一类（事实、语气、结构、格式） | 可以改图层。          |
| 会不会有人拿它直接对外发             | 不会。我觉得还是需要专业人士的 |

## ④ 错了怎么兜（2 分钟）

> 故意让它错一次，看它后面有没有补救机制。

| 记什么                               | 我填                                |
| --------------------------------- | --------------------------------- |
| 它有没有标来源 / 给置信度 / 提醒我核对            | 有提示我是假数据，需要接入真实数据                 |
| 我故意给错前提，它顺着编，还是纠回来                | 它不管这个。我在当前页面直接指挥ai工作，它提示我会新开页面操作。 |
| 兜底靠什么：规则校验 / 人工复核 / 可核对来源 / 什么都不兜 | 靠人工。                              |

## ⑤ 错一次多贵（2 分钟）

| 记什么                 | 我填                             |
| ------------------- | ------------------------------ |
| 最坏情况：这一步错了，下游要跟着改多少 | 我做一次页面，花费132个积分，免费积分不多，4词就用完了。 |
| 能不能撤回 / 有没有历史记录     | 能撤回。                           |
| 结论：错得起 / 错不起（选一个）   | 错的起。                           |

## ⑥ 不用它的替代（2 分钟）

| 记什么                   | 我填                                   |
| --------------------- | ------------------------------------ |
| 明天它消失了，我用什么顶上         | 还是设计师。                               |
| 那个替代方案差在哪（贵、慢、要学、没人会） | 它相对于framer，更多的是在设计资料的沉淀这一段，它能导出代码原型  |
| 结论：换得掉 / 换不掉（选一个）     | 它已经提供了插件，可以调用。它现在是有使用个数限制的，换的掉。但习惯在那 |

## 最后三问（一句话就够）

| 问题               | 我填                                     |
| ---------------- | -------------------------------------- |
| 1. 它省的那一步，值不值这个价 | 省的是设计师找组件模板这一段。我还没法评估价格，请ai这块做下详细的对比调查 |
| 2. 它的门槛在模型，还是在别处 | 它的门槛在于设计和原型编辑                          |
| 3. 我会不会留下，为什么    | 会，我想学习，做好看的设计。但我觉得它可能跟适合设计师。是由专项人群属性的。 |

---

**三条必须给结论**：① 值不值这个价；② 门槛在模型还是在别处；③ 会不会留下。
