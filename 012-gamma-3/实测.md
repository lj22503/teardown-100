# 012 · Gamma · 实测表（20 分钟）

> 产品页：https://www.producthunt.com/products/gamma-3
> 官方一句话：A new medium for presenting ideas. Powered by AI.
> 框架：[[04-概念-应用层六维]]（六条，每条都要一个具体证据）
> 写完跟我说一句「Gamma 实测好了」。

## 先做一件事（8 分钟）

**照做**：把你一篇真实长文导成 PPT，再导出 pptx 用 PowerPoint 打开

做完停下来，下面六维都从这一次体验里取证据。


目前来看它是嵌入式。我对于这个产品有2个点非常喜爱，一个是它内置很多高审美的场景，另外一个是它在对话框做的引导很场景化。对于新手很有帮助。
https://gamma.app/

它是面向咨询，教育，营销，产品设计的人士，支持ppt，网站，简历等非常多的模板，提示词。

我考虑逆向gamma，然后发现：Gamma 的工作流设计刻意将“人类判断”嵌入到 AI 管道的多个节点，而非一次性的 prompt-to-deck。我觉得下一步整理它的工作流很有用。

给我的启示是，原子化的内容可怎么拆解并串联成工作流。那逆向它可用做什么，就可用看看它的用户在用它来做什么，我们能否把它原子化嵌入到用户的工作流中去。

## ① 替掉哪一步

> 它接管的这步，原来是怎么做的。

| 记什么                    | 我填                                   |
| ---------------------- | ------------------------------------ |
| 这件事原来谁做、怎么做            | 人自己做，做出来没有审美，是设计师或者专业人士的。            |
| 原来要多久（分钟），现在要多久        | 现在gamma能够高效的去做，打破下限。                 |
| 原来花多少钱（人工/外包/工具），现在花多少 | 原来可能花钱也搞不出好看的，现在月付的方式，所以如果是年终去搞，就值得。 |

## ② 脏活谁干（5 分钟）

> 数据、权限、格式的麻烦，它自己啃还是甩回给你。

| 记什么                            | 我填                       |
| ------------------------------ | ------------------------ |
| 它要求我手动补了什么（导数据、改格式、给权限、写说明），几次 | 它需要我给到任务的上下文             |
| 哪些是我本来就得做的，哪些是它没做好推给我的         | 它把选择和判断交给了人，审美交给了结构化的工作流 |
| **甩回来的那部分，是不是这个品类真正的门槛**       | 甩回来的部分不是门槛，是资源方的判断。      |

## ③ 出来能不能用（3 分钟）

| 记什么                      | 我填              |
| ------------------------ | --------------- |
| 直接用 / 改一两处 / 基本重做（选一个）   | 能               |
| 如果要改，改的是哪一类（事实、语气、结构、格式） | 改的是目标，但它可用切换颗粒度 |
| 会不会有人拿它直接对外发             | 能。它很好看。         |

## ④ 错了怎么兜（2 分钟）

> 故意让它错一次，看它后面有没有补救机制。

| 记什么                               | 我填                      |
| --------------------------------- | ----------------------- |
| 它有没有标来源 / 给置信度 / 提醒我核对            | 它在你给出指令后，会通过交互给你进一步明确指令 |
| 我故意给错前提，它顺着编，还是纠回来                | 它会跟你确认                  |
| 兜底靠什么：规则校验 / 人工复核 / 可核对来源 / 什么都不兜 | 规则校验。它的底座是一些列的工作流。      |

## ⑤ 错一次多贵（2 分钟）

| 记什么                 | 我填                                           |
| ------------------- | -------------------------------------------- |
| 最坏情况：这一步错了，下游要跟着改多少 | 比如我现在免费试用，生成20张ppt，结果只能生成10张，就一定要进入下一步的付费环节。 |
| 能不能撤回 / 有没有历史记录     | 你完全还可用自己编辑。                                  |
| 结论：错得起 / 错不起（选一个）   | 错的起                                          |

## ⑥ 不用它的替代（2 分钟）

| 记什么                   | 我填                  |
| --------------------- | ------------------- |
| 明天它消失了，我用什么顶上         | 可用豆包。但用过了好的，可能很难平替。 |
| 那个替代方案差在哪（贵、慢、要学、没人会） | 在于不够好用。             |
| 结论：换得掉 / 换不掉（选一个）     | 换的掉。但成本大。           |
