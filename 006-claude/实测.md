## T1 主链路（10 分钟）

**动作**：让它做完一件你昨天真做过的工作，一次做完，中途不教它

| 记什么                    | 我填             |
| ---------------------- | -------------- |
| 从开始到出第一个能用的结果，几步 / 几分钟 | gmail注册，然后聊天可用 |
| 哪一步停下来想「下一步该干嘛」        |                |
| 结果改了几次才敢用              | 没测到            |

## T2 边界（5 分钟）— 必须给结论

**喂什么**：专业黑话密集、中英混杂、或自相矛盾的指令

| 记什么                       | 我填                                  |
| ------------------------- | ----------------------------------- |
| 它有没有主动指出矛盾 / 不确定          | 有，我让他把我github的项目统统看了一遍，它能够很好的指出我的问题 |
| 错的时候是「明显错」还是「通顺地错」        | ——没测到                               |
| 有没有提醒你核对来源                |                                     |
| **结论：失效场景成立 / 不成立（一句理由）** |                                     |

## T3 钱（3 分钟）

**动作**：找到免费额度用完的那一刻

| 记什么            | 我填             |
| -------------- | -------------- |
| 墙在哪一步，弹什么文案    | 直接被封号了，说账号有问题。 |
| 免费版够不够你日常用     | 不够用吧，很少        |
| 它主卖的是额度、能力还是席位 | 能力             |

## T4 时间（2 分钟）

从打开到能产出，掐表。没测就写「未测」，不要估。

| 记什么     | 我填   |
| ------- | ---- |
| 几分钟     | 5min |
| 要不要先读教程 | 不用   |

## T5 命门（5 分钟）— 必须给结论

**要回答**：不用它，你原来的方式多花多少时间；省的是时间还是能力

| 记什么              | 我填    |
| ---------------- | ----- |
| 我的答案             | 省的是能力 |
| 支持这个答案的具体证据（一句话） | 它比我强  |

## 最后四个问题

| 问题                   | 我的答案                        |
| -------------------- | --------------------------- |
| 1. 我原以为它是给谁用的        | 普通人用的                       |
| 2. 用完发现它其实在保护 / 提供什么 | 现在大部分账号被封，国内应该只有部分人买到了最高订阅。 |
| 3. 我卡在哪一步            | 我卡在账号上。                     |
| 4. 会不会留下，为什么         | 现在用Claude cli。+其他的大模型。      |
