## T1 主链路（10 分钟）

**动作**：用你自己的 3-5 篇真实笔记，走它宣称的核心动作（建对象/加关联/建库），最后看它能不能帮你把这几篇串起来

| 记什么                    | 我填              |
| ---------------------- | --------------- |
| 从开始到出第一个能用的结果，几步 / 几分钟 | 1min，流程很顺       |
| 哪一步停下来想「下一步该干嘛」        | 无需想，节省人力，给到决策建议 |
| 结果改了几次才敢用              | 可以直接用           |

## T2 边界（5 分钟）— 必须给结论

**喂什么**：贴两份互相矛盾的材料，或一篇 8000 字以上术语密集的长文

| 记什么                       | 我填  |
| ------------------------- | --- |
| 它有没有主动指出矛盾 / 不确定          | ——  |
| 错的时候是「明显错」还是「通顺地错」        | ——  |
| 有没有提醒你核对来源                | ——  |
| **结论：失效场景成立 / 不成立（一句理由）** |     |

不存在这个边界，它不做这个判断。它的作用是提升效率，而不是帮助用户做文档的校对。

## T3 钱（3 分钟）

**动作**：只用免费版，找它在第几步拦你

| 记什么            | 我填                                                 |
| -------------- | -------------------------------------------------- |
| 墙在哪一步，弹什么文案    | 1，在试用免费工具箱后，7天之后会进入订阅模式                            |
| 免费版够不够你日常用     | 2，够用，但如果产生依赖之后不太够用，因为一定会用到它的AI功能。它的AI功能是内置的，不是外放的。 |
| 它主卖的是额度、能力还是席位 | 3，卖额度。包括发布作品的额度，私人空间的额度。                           |

## T5 命门（5 分钟）— 必须给结论

**要回答**：它到底省掉了「搭结构」这一步，还是只是换了个地方让你搭

| 记什么              | 我填                   |
| ---------------- | -------------------- |
| 我的答案             | 省了信息收集的难度            |
| 支持这个答案的具体证据（一句话） | 它丰富的自动识别功能，能够快速收藏内容。 |

## 最后四个问题

| 问题                   | 我的答案                                        |
| -------------------- | ------------------------------------------- |
| 1. 我原以为它是给谁用的        | 收藏癖用的，结果它重点在为输出做差异化                         |
| 2. 用完发现它其实在保护 / 提供什么 | 节约时间，提供效率                                   |
| 3. 我卡在哪一步            | 我在想，我是不是一个面向流量的销售者，还是真的想积累自己的认知？这可能是它的用户分野。 |
| 4. 会不会留下，为什么         | 现在很实惠，内置了大模型叠加这么多功能但比大模型省钱。                 |
