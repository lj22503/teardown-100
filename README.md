## 三条规矩

1. **事实只写可核实的**（官网 / 定价页 / 帮助中心 / 用户评论），并在报告末尾附来源链接。
2. **未公开的写推断，但必须标 `[推断]` 并写依据**；不写假精度数字。
3. **一手体验署名**（体验者：燃冰），不冒充他人实测。
